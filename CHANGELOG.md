# Changelog

## [Version 1.0.0] - 2024-05-01
- Initial release of the mod.

## [Version 1.1.0] - 2025-02-27
- Updated for Minecraft Fabric 1.21.1

### Changed
- Ho-Oh now has weather boost in Sunny weather.
- Removed Ho-Oh from skylands_summer and put Rayquaza there.
- The time between a spawn event now ranges between 12.5 and 25 minutes.

## [Version 1.1.1] - 2025-03-02
- Legends just got easier to find!

### Timer Logic
- Legendary spawn timer is now randomly between 12.5 minutes and 18.5 minutes
- Spawn event chance raised from 35% to 40%

### Spawn Changes
- Volcanion and Reshiram now spawn in Terralith Volcanic Peaks
- Zekrom now spawns in Terralith Yosemite Lowlands and Yosemite Cliffs
- Regigigas now spawns in Terralith Fungal Caves
- Registeel now spawns in Terralith Deep Caves and Infested Caves
